# 草稿

独立的 Android 原生草稿纸，面向小米平板和手写笔。

- 无边界矢量画布，单指平移、双指缩放。手指双击将该位置移到画布中央，100% 时放大到 200%，其他倍率回到 100%。低于 70% 时隐藏格点，落笔粗细以屏幕显示为准。
- 手写笔书写，力度越大笔画越粗，支持系统防误触取消事件；手指不落墨。
- 小米笔下键短按撤销，按住 200ms 临时橡皮、松开回笔。上键短按在上次笔尖悬停处打开扇形工具菜单，再按关闭。支持上键长按的机型可用它进入框选待命。普通键盘翻页键不受影响。
- 四种常用笔色，笔粗细与书写压感灵敏度按 0.1 步进调节，灵敏度设为 0 时使用固定线宽。书写力度阈值可设为 0–200，低于阈值时断笔，设为 0 时关闭过滤。橡皮大小和压感灵敏度可调，这些设置会自动保存。
- 圆形局部笔段橡皮，擦除断口为圆形端帽；笔压越大擦除圈越大，压感灵敏度可调，支持快速扫过和整次撤销。
- 进入框选后，用笔尖描出任意形状，抬笔自动闭合。拖动选区可移动内容，拖右下角可等比例缩放，轻点选区可打开复制、粘贴、删除和取消菜单。用笔轻点框外可退出框选。工具菜单右下可总览或清空画布，画布左下显示当前缩放比例，轻点可恢复 100%。菜单外的首次笔触或手指轻点会收起菜单。
- 自动保存一张草稿到 App 私有目录，重新打开会恢复笔迹和画布位置。

短按笔的上键，在扇形菜单中点「同步」。在同一界面配对 Mac、查看连接状态并开关两个传输方向，两个方向共用一条加密连接。

- **平板截图 → Mac 剪贴板**：开启截图监控后，平板三指截图会发到 Mac 剪贴板，传输结束后清理平板截图。
- **Mac 剪贴板 → 草稿纸**：从 Mac 菜单栏 PadPaste 复制配对码或导出配对文件，在平板「同步」中完成一次配对。配对后打开草稿纸，用 QQ 等工具截图并复制图片。题图会在预计放置处显示半透明预览，点图中央「导入」，或直接拖右下角开始导入。题图在屏外时，从「查看题图」气泡发出绿色涟漪。题图导入后默认选中，也可用手指轻点选中，拖动图片移动，拖右下角等比缩放。滑动空白处可平移画布并保留选中，轻点空白处或在图外落笔会取消选中。

传输时，草稿纸左上角显示进度和方向，轻点进度环可取消尚未完成的传输。两端更新后，如果正在上传或下载，反向传输会被拦截并在平板弹出提示。

在草稿纸「同步」页和 Mac 的 PadPaste 菜单开启「蓝牙备用」。两端优先走 Wi-Fi。通道切换时，当前图片在新通道重新开始发送，平板弹出提示。蓝牙版图片长边最多 1280 像素，需 Android 12+、附近设备权限和 Mac 蓝牙权限。

```sh
cd android-canvas
./gradlew testStandardDebugUnitTest lintStandardDebug assembleStandardDebug assembleStandardDebugAndroidTest
```

小米兼容构建使用系统硬编码的绘图免拦截包名 `com.miui.pen.demo`（界面名称为「草稿·小米笔」），使下键长按不会打开系统笔记。它仍是本项目自行签名的普通应用，不授予小米系统权限，不修改原笔记，不改变全局游戏模式。普通构建保持 `io.github.fantuani.draftcanvas`。该兼容行为依赖当前 HyperOS 固件，更新系统后需复测。小米平板 6 Pro 的 HyperOS 会优先将上键长按用于系统截图，在此机型上可短按上键并点扇形菜单左下的「框选」，拖动笔尖并抬笔完成框选。

Android 8+，JDK 17、SDK 35。首次连接真机时安装 debug APK 和 androidTest APK，运行：

```sh
adb shell am instrument -w io.github.fantuani.draftcanvas.debug.test/io.github.fantuani.draftcanvas.CanvasTestRunner
```

Debug 包名带 `.debug`，可与正式版共存；小米按键免拦截需用正式版验证。

测试使用合成笔/触摸事件验证 View 交互和局部擦除绘制；实际小米笔的压力与手掌检测仍需真笔体验确认。

擦除采用共享采样点、可见区间和笔段包围盒树，后台分区栅格缓存、前台即时擦除预览；设计参考 [Xournal++ 的区间式擦除](https://github.com/xournalpp/xournalpp/blob/master/src/core/model/eraser/ErasableStroke.cpp)，使用独立 Java 实现。
